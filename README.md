# DSTech suporte

Atualização:

Extensão de atendimento: Respostas Rápidas | Guia de utilização

1. Instalação
Baixe o arquivo da extensão.
Abra o Google Chrome e acesse chrome://extensions.
Ative o Modo do desenvolvedor.
Clique em Carregar sem compactação.
Selecione a pasta extraída da extensão.

2. Como utilizar
Acesse o Omini ou Hubsoft.
Clique no campo onde deseja digitar.
Clique no botão azul D, localizado no canto superior direito.
Escolha a categoria OS ou Omini.
Pesquise ou selecione o modelo desejado.
O texto será inserido automaticamente no campo de digitação.

3. Observações
Os modelos podem ser inseridos junto com textos já digitados.
Os modelos podem ser alterados, excluidos e novos podem ser adicionados conforme a necessidade do usuário.
Os campos representados por XXX, XXXX e similares devem ser preenchidos manualmente.
A extensão não envia mensagens automaticamente.
Para atualizar a extensão, basta substituir os arquivos antigos e carregá-la novamente pelo Chrome.
